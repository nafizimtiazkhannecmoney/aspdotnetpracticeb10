ASP.NET Core & ngrok Setup Guide

How to expose your local ASP.NET Core API to the public internet for webhooks and testing.

The Core Mental Model

External Service (Facebook, Stripe, etc.) sends request → ngrok Cloud URL (https://xyz.ngrok-free.dev) → ngrok Tunnel Agent (on your PC) → Localhost (http://localhost:5005) → Your ASP.NET Core Controller

1

Download ngrok & Sign Up

  1. Go to ngrok.com and sign up for a free account.
  2. Download the Windows version (comes as a .zip file).
  3. Extract the zip folder. Inside, you will see a single executable file: ngrok.exe.
2

Place ngrok.exe So Windows Can Find It

To run ngrok from any Command Prompt window without PATH errors:

  • Copy ngrok.exe and paste it into: 
    C:\Windows\System32\
    (Because System32 is in Windows PATH by default, you can now run ngrok anywhere).
3

Add Your Auth Token (First Time Only)

  1. Log into your dashboard at dashboard.ngrok.com.
  2. Under Getting Started → click Your Authtoken and copy your token.
  3. Open Command Prompt (cmd) and execute:
ngrok config add-authtoken YOUR_AUTHTOKEN_HERE
Done! This configures ngrok once. You never need to repeat this step again on this PC.
4

Check Your Local ASP.NET Core Port

Inside your ASP.NET Core project, check Properties/launchSettings.json to find your local HTTP port:

{
  "applicationUrl": "https://localhost:7013;http://localhost:5005"
}

Run your API (Press F5 in Visual Studio or run dotnet run). Verify in your browser that your local endpoint works:

http://localhost:5005/weatherforecast
Important: Keep your ASP.NET Core API running. If your app stops, ngrok has nothing to connect to!
5

Start the ngrok Tunnel

Open a separate Command Prompt window and tell ngrok to forward to your HTTP port (5005):

ngrok http 5005

ngrok will launch and display a session status screen:

Session Status    online
Account           your-email@gmail.com (Plan: Free)
Forwarding        https://unshabby-grievedly-zella.ngrok-free.dev -> http://localhost:5005
6

Test Your Live Public URL

Copy your public HTTPS ngrok URL and append your controller route:

https://unshabby-grievedly-zella.ngrok-free.dev/weatherforecast
  1. Open this link in any browser or on your phone (using cellular data off Wi-Fi).
  2. Free Tier Notice: When opened in a web browser, click the blue "Visit Site" button on ngrok's initial warning screen.
  3. You will see your local ASP.NET Core JSON output returned over the internet!
Webhook bonus: Automated webhook POST requests from Facebook, Stripe, or other servers bypass that browser warning screen automatically.
✓

Daily Quick-Start Cheat Sheet

Every time you want to test webhooks in the future, just do two things:

  1. Start your ASP.NET Core project in Visual Studio (running on port 5005).
  2. Open Command Prompt and run: ngrok http 5005.
  3. Copy the new https://....ngrok-free.dev URL and paste it into Facebook / Stripe / your external service's webhook dashboard.
