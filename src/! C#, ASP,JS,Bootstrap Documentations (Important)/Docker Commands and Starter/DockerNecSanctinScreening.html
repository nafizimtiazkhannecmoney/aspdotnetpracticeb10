ASP.NET Core 8.0 + Docker Tutorial

This tutorial walks through building, running, logging, and sharing your ASP.NET Core 8.0 project using Docker.

1. Build Your Project

dotnet publish -c Release

This prepares your app for deployment.

2. Dockerfile Example

# Build stage
FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /src
COPY ["NecSanctionScreening.csproj", "."]
RUN dotnet restore "NecSanctionScreening.csproj"
COPY . .
RUN dotnet publish "NecSanctionScreening.csproj" -c Release -o /app/publish /p:UseAppHost=false

# Runtime stage
FROM mcr.microsoft.com/dotnet/aspnet:8.0 AS final
WORKDIR /app
EXPOSE 8080

# Create logs directory
RUN mkdir -p /app/logs

# Copy published output
COPY --from=build /app/publish .

# Environment variable
ENV DOTNET_ENVIRONMENT=Production
ENV LOG_PATH=/app/logs

ENTRYPOINT ["dotnet", "NecSanctionScreening.dll"]

3. Build & Run Docker Image

  • Build: 
    docker build -t myapp:1.0 .
  • Run: 
    docker run -d -p 8080:80 myapp:1.0
  • Run with environment: 
    docker run -d -p 8080:80 -e DOTNET_ENVIRONMENT=Production myapp:1.0
  • Run with logs mounted: 
    docker run -d -p 8080:80 -v ./logs:/app/logs myapp:1.0

4. Serilog Configuration

Add this to appsettings.json:

{
  "Serilog": {
    "MinimumLevel": "Information",
    "WriteTo": [
      {
        "Name": "File",
        "Args": {
          "path": "/app/logs/app.log",
          "rollingInterval": "Day",
          "shared": true
        }
      },
      { "Name": "Console" }
    ]
  }
}

And in Program.cs:

using Serilog;

var builder = WebApplication.CreateBuilder(args);
builder.Host.UseSerilog((context, services, configuration) =>
    configuration.ReadFrom.Configuration(context.Configuration));

builder.Services.AddControllers();
var app = builder.Build();
app.MapControllers();
app.Run();

5. Sharing Docker Images

Option A: Docker Hub

docker login
docker tag myapp:1.0 yourdockerhubusername/myapp:1.0
docker push yourdockerhubusername/myapp:1.0
docker pull yourdockerhubusername/myapp:1.0

Option B: Save/Load (Offline)

docker save -o myapp.tar myapp:1.0
docker load -i myapp.tar
